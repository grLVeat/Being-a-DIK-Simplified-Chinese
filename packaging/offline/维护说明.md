# 离线安装与手动路径

本版 package.json 的 offline_only 为 true。安装器先核对游戏中已有的完整基础汉化，再检查显式 -ArchivePath 或随包 cache/BAD_CN_0.09.rar。需要基础包但找不到本地文件时直接退出，不调用网络下载；文件损坏时也不会回退到联网。

完整解压本包后，在解压目录打开 PowerShell，可指定游戏目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\installer.ps1 -Action Install -GamePath "X:\SteamLibrary\steamapps\common\Being a DIK\Being a DIK Seasons 1 and 2"
```

如需导入存放在其他位置的同版原始 RAR，可追加 -ArchivePath "X:\Archives\BAD_CN_0.09.rar"。无须改名或预先解压该文件。将 Action 改为 Check 或 Uninstall 可指定目录检查或卸载。自动化可加 -NonInteractive，缺少信息或失败时以非零状态码退出。

# 校验与修订

package.json 固定基础 RAR 的 SHA256、989 个基础安装文件、目标游戏脚本资源指纹以及 4 个修订文件的哈希。SHA256SUMS.txt 列出所有随包文件（不含清单自身）的校验值；ZIP 旁的 .sha256 校验整个 ZIP。它们用于检查损坏，不是数字签名；请从可信分享者处获取完整 ZIP。

原始基础 RAR：cache/BAD_CN_0.09.rar；286,811,442 字节。
SHA256：92ca5221e51db8422a038146ffc9121f6ad4e7b1d2a9e4138a66e6a8a05f8e77

payload/game/cn_polished/cn_polished.json 是可读 UTF-8 数据。dialogue 以翻译编号和原文定位，strings、phone_strings 和 templates 处理界面、手机及动态文本。修改译文必须保留 [变量]、{格式标签}、%s 等参数；不要删除匹配用的 en / previous / file / line / who 字段。更新数据后也须更新 package.json 与校验清单，否则安装器会拒绝。

当前版本只保证本包标出的 Steam 0.8.3 / CN0.09 组合。升级游戏或基础汉化后应重新提取、对照并在引擎中验证，不能只改版本号或跳过哈希检查。

发布时保留本包的 cache/BAD_CN_0.09.rar，这是无需原下载链接的关键。不要混入使用者的游戏本体、存档、.badik-cn-community 安装备份或其他本机缓存。原始基础 RAR 以及其中的上游说明均保持完整，不重新授予第三方内容许可。
