Being a DIK 第 1—2 季简体中文社区修订包
版本：2026.10.03；适用：Windows / Steam 0.8.3 / 第 1、2 季（EP1—8）

使用方法
1. 自备游戏及第二季 DLC，退出游戏，把整个 ZIP 解压到一个新文件夹。
2. 双击“安装汉化.cmd”。安装器会尝试找到 Steam 游戏；找不到时按提示输入游戏文件夹。
   应选择同时包含 BeingADIK.exe、game、renpy 的那一层。
3. 第一次安装会从原作者 GitHub 发布页获取约 287 MB 的 CN0.09 基础汉化，
   校验文件后安装本次完整修订。完成后照常从 Steam 启动游戏。
4. 游戏中不需要联网翻译。“检查安装.cmd”可核验安装，“卸载汉化.cmd”恢复安装前文件。

若 GitHub 下载失败
打开 https://github.com/Vetoyi/CN_Patch.Being_A_DIK/releases/tag/CN_Ver0.09
手动下载 2022.09.07_BAD.CN_Ver0.09.GameVer0.8.3.rar。
在本工具文件夹内新建 cache 文件夹，把下载文件改名为 BAD_CN_0.09.rar 放入，再重试安装。
不要事先解压 RAR。工具自动解开两层压缩并检查 SHA256；下载文件只存在使用者本机。

请保留游戏目录内的 .badik-cn-community 文件夹，这是安装前备份及卸载依据。
卸载会恢复安装前状态：原先是英文就恢复英文，原先有旧汉化就恢复旧汉化。
它不会修改玩家存档，也不转换存档。旧存档中已记录的历史内容不保证全部回溯改写。
第三季、其他游戏版本及修改过脚本资源包的版本不适用；安装器会检查版本指纹。
与其他覆盖同名脚本的 MOD 叠加使用未经验证。游戏更新后请先卸载旧补丁再核对适用版本。

分享方式
请分享本 ZIP 原包及说明即可。无需复制你的游戏目录、存档、缓存或本机安装备份。
本包包含本次修订数据、脚本、安装工具与 UnRAR；基础汉化由使用者从原作者发布处获取。
本包不包含游戏本体、Steam 组件、上游字体或音乐资源。

更多内容见“修订与验证.md”“来源与使用说明.md”“维护说明.md”。
