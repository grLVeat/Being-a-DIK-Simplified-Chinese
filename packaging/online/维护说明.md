# 手动路径与离线安装

在解压目录打开 PowerShell，可指定游戏目录与基础 RAR：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\installer.ps1 -Action Install -GamePath "X:\SteamLibrary\steamapps\common\Being a DIK\Being a DIK Seasons 1 and 2" -ArchivePath "X:\Downloads\2022.09.07_BAD.CN_Ver0.09.GameVer0.8.3.rar"
```

将 Action 改为 Check 或 Uninstall 可指定目录检查或卸载。自动化可加 -NonInteractive，缺少信息或失败时以非零状态码退出。

# 校验与修订

package.json 固定基础 RAR 的 SHA256、989 个基础安装文件、目标游戏脚本资源指纹以及 4 个修订文件的哈希。SHA256SUMS.txt 列出包内文件校验值。它们用于检查损坏，不是数字签名；请从可信分享者处获取 ZIP。

payload/game/cn_polished/cn_polished.json 是可读 UTF-8 数据。dialogue 以翻译编号和原文定位，strings、phone_strings 和 templates 处理界面、手机及动态文本。修改译文必须保留 [变量]、{格式标签}、%s 等参数；不要删除匹配用的 en / previous / file / line / who 字段。更新数据后也须更新 package.json 与校验清单，否则安装器会拒绝。

当前版本只保证本包标出的 Steam 0.8.3 / CN0.09 组合。升级游戏或基础汉化后应重新提取、对照并在引擎中验证，不能只改版本号或跳过哈希检查。

本包故意不附玩家存档、个人路径、测试截图、原版脚本或游戏资源包。若另行分享本机安装目录，请不要把 cache、.badik-cn-community 备份目录和个人数据混进发布包。
