# Being a DIK — Simplified Chinese Community Revision

[简体中文说明](README.md)

An unofficial Simplified Chinese localization revision for **Windows 64-bit, Steam version 0.8.3, Seasons 1 and 2 (EP1–8)**. You must own the game and Season 2 DLC. This package does not contain a standalone copy of the game and does not support Season 3.

## Download and install

Use the **[full offline ZIP](https://github.com/grLVeat/Being-a-DIK-Simplified-Chinese/releases/download/v2026.10.03/BeingADIK_CN_0.8.3_S1-S2_20261003_OFFLINE.zip)** (about 288.5 MB). It includes the original baseline translation archive, our revisions, and the extraction utility. Installation does not need the original download link or an internet connection.

1. Exit the game and extract the entire ZIP, keeping the `cache` folder.
2. Run `安装汉化.cmd` (or `install.cmd`). If prompted, select the folder containing `BeingADIK.exe`, `game`, and `renpy`.
3. Launch the game normally through Steam. Use `check.cmd` to verify installation or `uninstall.cmd` to restore the pre-install state.

Keep the `.badik-cn-community` folder in the game directory: it contains installation backups. The installer does not modify or convert player saves. Steam and the game may have their own network requirements.

The smaller **[online ZIP](https://github.com/grLVeat/Being-a-DIK-Simplified-Chinese/releases/download/v2026.10.03/BeingADIK_CN_0.8.3_S1-S2_20261003.zip)** usually downloads about 287 MB on first installation. Both packages and SHA-256 files are on the [latest release page](https://github.com/grLVeat/Being-a-DIK-Simplified-Chinese/releases/latest). GitHub's automatically generated **Source code** archives are not installers.
