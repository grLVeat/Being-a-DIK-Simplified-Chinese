## 三步安装

1. 退出游戏，把 ZIP **完整解压**到一个新文件夹；离线版请保留 `cache` 文件夹。
2. 双击 **`安装汉化.cmd`**。若未自动找到游戏，选择同时包含 `BeingADIK.exe`、`game`、`renpy` 的目录。
3. 完成后照常从 Steam 启动。可用 `检查安装.cmd` 核验，或用 `卸载汉化.cmd` 恢复安装前状态。

请保留游戏目录内的 `.badik-cn-community`，其中有安装前备份。安装器不修改或转换玩家存档。游戏版本不符、文件损坏或存在冲突时会停止；详情见[常见问题](docs/FAQ.md)。

## 本次修订

校对 15,909 条目标文本，改写 12,839 条；另修订手机、人物档案、事件记录及遗漏选项，修复翻译编号失配和第 6 章午餐后的错误跳转。保留剧情所需的社团简称、音乐曲名及英语练习文本。

离线安装器通过 32 项检查及完整安装、检查、卸载恢复测试；相同翻译数据已在实际游戏引擎中验证。**未逐一游玩所有剧情分支**，也不将第一、二季全部原有译文声称为本次重新翻译。[完整范围与验证记录](docs/TRANSLATION_NOTES.md)
