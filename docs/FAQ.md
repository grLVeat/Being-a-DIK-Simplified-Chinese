# 常见问题

## 离线版和在线版有什么区别？

翻译修订内容相同。离线版约 288.5 MB，内置基础汉化和所需解压工具，安装不依赖原链接；在线版约 1.6 MB，需要时从原项目下载约 287 MB 基础汉化。推荐离线版。请保留完整解压目录，尤其是离线版的 `cache` 文件夹。

## 下载了 Source code，为什么找不到完整安装包？

GitHub 自动生成的 `Source code (zip)` / `Source code (tar.gz)` 是仓库快照。请到[发布页](https://github.com/grLVeat/Being-a-DIK-Simplified-Chinese/releases/latest)下载文件名包含 `BeingADIK_CN_0.8.3_S1-S2_20261003` 的安装 ZIP，推荐结尾带 `_OFFLINE.zip` 的版本。

## 只买了第一季，或者正在玩第三季，可以装吗？

本版针对 Windows 64 位、Steam 0.8.3、第 1、2 季及第二季 DLC（EP1—8）。没有验证只安装第一季的情况；第三季和其他版本不适用。安装器会核对目标资源指纹，不要改版本号或跳过校验强行安装。

## 自动找不到游戏目录怎么办？

按安装器提示手动选择同时包含 `BeingADIK.exe`、`game`、`renpy` 的那一层目录。Steam 的 `common\Being a DIK` 外层文件夹可能还包含 `Being a DIK Seasons 1 and 2` 子目录，应选择后者。也可使用[手动指定目录](INSTALL.md#手动指定目录)命令。

## 提示版本指纹不匹配怎么办？

先确认是 Steam 0.8.3，并已安装第二季 DLC。其他 MOD 或旧补丁若修改了目标脚本资源包，也可能造成不匹配。先保留现有修改及存档备份，再恢复到匹配的游戏版本。不要直接改安装器中的哈希来绕过检查。

## 离线版为什么提示缺少或损坏的基础 RAR？

确认已完整解压 ZIP，且 `cache/BAD_CN_0.09.rar` 存在。该文件应为 286,811,442 字节，SHA-256 为：

```text
92ca5221e51db8422a038146ffc9121f6ad4e7b1d2a9e4138a66e6a8a05f8e77
```

离线版遇到缺失或损坏会停止，不会联网补下。请重新获取完整离线 ZIP，并按[校验下载](INSTALL.md#校验下载)检查；也可用 `-ArchivePath` 指定同版原始 RAR。

## 已装旧汉化，还能安装吗？

安装器会检查已有基础文件。完整匹配 CN0.09 时直接安装修订；需要覆盖的文件会备份。覆盖同名脚本的其他 MOD 可能发生冲突，叠加使用未经验证。若提示有额外脚本覆盖基础内容，应先查清其来源并恢复一致状态。

## 会影响存档吗？

安装器不会编辑或转换玩家存档。已进行独立测试存档的保存和读取验证，但没有遍历每种玩家存档或每条剧情分支。旧存档已经写入的手机、历史记录等内容不保证全部被回溯改写。

## 为什么还会出现英文？

DIK/HOT/ALPHA 等名称、音乐曲名及英语课练习需要的英文会保留。若普通对白、选项或界面仍为英文，可反馈章节、所在场景、角色和相关文字。游戏版本差异、旧存档历史记录及其他 MOD 也可能影响显示。

## 安装中断、文件后来被修改，或卸载失败怎么办？

先退出游戏并关闭其他安装器窗口，保留游戏目录的 `.badik-cn-community`。安装器会识别中断的安装记录；排除文件占用后按提示重试。若提示备份缺失或损坏，应停止并保留现有文件以便排查。

安装后文件被修改时，重装会停止。卸载会先保留修改后的冲突副本，再恢复安装前文件，冲突副本位于 `.badik-cn-community/conflicts/`。如果安装前已有旧汉化，卸载后恢复的是旧汉化，并非必定恢复英文。

## 如何反馈或参与修订？

使用[问题模板](https://github.com/grLVeat/Being-a-DIK-Simplified-Chinese/issues/new/choose)，优先提供最少必要的文本信息：补丁版本、离线/在线版、游戏版本、发生位置、当前文字及建议译法。角色姓名可以保留，玩家自定义姓名可用 `[玩家]` 替代。

不要上传完整游戏、完整存档、安装备份或未脱敏日志。日志中若含 Windows 用户名或个人文件路径，请先替换为 `<用户>` / `<游戏目录>`。截图不是必需项；可用文字说明，避免附带无关游戏画面。

修改翻译数据前请阅读[修订与维护说明](TRANSLATION_NOTES.md)。数据中的变量、格式标签与匹配字段不能随意删除。

## 可以转发或二次发布吗？

请保留来源、原署名、许可说明和非商用要求，不销售本包，不把游戏本体、自己的存档或安装备份一起打包。离线分享时同时保留完整 ZIP 与对应 `.sha256` 文件。新增代码的 MIT 许可仅覆盖明确列出的代码，不扩展到整个汉化包或第三方资源。
