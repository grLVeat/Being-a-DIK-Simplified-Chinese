# 修订、验证与维护说明

## 修订范围

本项目以 [Vetoyi CN_Ver0.09](https://github.com/Vetoyi/CN_Patch.Being_A_DIK/releases/tag/CN_Ver0.09) 为基础，针对既有机翻和遗漏英文进行简体中文修订。基础汉化覆盖第 1—2 季 EP1—8；本次没有重译第一、二季的全部原有译文。

| 项目 | 数量与处理 |
| --- | --- |
| 目标文本 | 校对 15,909 条，其中改写 12,839 条；包含对白和界面字符串 |
| 手机文本 | 校对 1,167 条，修订 739 条 |
| 人物档案、事件记录等 | 补入 197 条 |
| 额外菜单选项 | 补入 89 条 |
| 翻译编号失配 | 修复 52 处游戏更新导致的目标匹配问题 |
| 早期章节遗漏对白 | 补入 20 处 |
| 第 6 章午餐后跳转 | 修复旧补丁的错误目标，使其与原游戏一致 |

这些计数表示不同处理集合，可能与运行时映射计数口径不同，不应简单相加为“全游戏新译行数”。目标文本主要涉及第 7、8 章主线、自由探索、课程及相关界面。DIK/HOT/ALPHA 等社团名称、音乐曲名和英语课练习所需英文予以保留。

## 运行时与数据

修订数据保存在安装包的 `payload/game/cn_polished/cn_polished.json`，以 UTF-8 编码存储。运行时脚本在基础汉化之上替换已核对的对白与字符串，并处理部分旧翻译编号与动态显示文本。除单独的第 6 章旧补丁跳转修复外，修订不以改变剧情分支或玩家状态为目的。

- `dialogue` 保存翻译编号、原文及匹配字段和修订译文。
- `strings` 处理界面字符串。
- `phone_strings` 处理手机显示文字。
- `templates` 处理经过核对的动态文本。

如参与修改，请保留 `[变量]`、`{格式标签}`、`%s` 等占位符以及必要的转义；不要删除匹配所用的 `en`、`previous`、`file`、`line`、`who` 等字段。数据更新后必须同步生成 `package.json` 中的哈希及包内校验清单，不能靠跳过校验发布。

## 兼容性与维护

当前仅针对 **Steam 0.8.3 / 第 1—2 季 / Vetoyi CN0.09** 组合。更换游戏或基础汉化版本后，应重新提取文本、比对编号与资源指纹，并在引擎中验证。不能仅修改版本号、哈希或禁用检查来宣称兼容。

安装器保留安装前文件及操作记录；卸载恢复安装前状态，修改冲突另存副本。请勿将使用者的 `.badik-cn-community`、玩家存档、运行日志、本机缓存或游戏本体混入发行包。

## 从源码构建发行包

此节面向维护者；普通玩家请直接下载发布页的安装 ZIP。构建工具需要 Python 3.8 或更新版本，在仓库根目录执行：

```powershell
python tools/build_release.py
```

默认只构建在线包。构建离线包需自备哈希匹配的 CN0.09 原始 RAR；工具完全不联网：

```powershell
python tools/build_release.py --mode offline --base-archive "X:\Archives\BAD_CN_0.09.rar"
```

使用 `--mode all` 同时构建两种包；`--output "X:\Builds\badik-cn-new"` 可指定新的输出目录，默认输出到仓库的 `dist`。工具生成安装目录、ZIP 和对应 `.sha256`，若同名输出已存在会拒绝覆盖。

构建会校验包清单及输入文件完整性，不替代游戏运行验证。复制到构建结果中的既有验证报告仍是历史记录，不代表新修改已通过测试。改译文或脚本后需同步维护清单、重新验证，并记录新的版本与校验值。
